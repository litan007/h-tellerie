# Andazibe Hotel & Restaurant

Application React/Vite dédiée à la présentation de l’hôtel, des suites, du restaurant et des expériences d’Andasibe.

## Run locally

Prerequisites: Node.js

1. Install dependencies:
   `npm install`
2. Start the development server:
   `npm run dev`
3. Open the local URL shown by Vite in your browser.
